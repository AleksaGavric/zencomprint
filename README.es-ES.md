## Características

- **Alternar Comentarios y Prints**: Oculta o muestra rápidamente los comentarios y las instrucciones `print` en tu código para limpiar tu vista. Una vez ocultados, los comentarios y prints siguen presentes en el archivo pero no se muestran, lo que facilita concentrarse en la lógica.
- **Soporte Multiidioma**: Constantemente agregamos más idiomas para que puedas usar *ZenComPrint* en todos tus proyectos.
- **Acceso Simple**: Mediante un atajo simple, puedes alternar la visualización de comentarios y prints, facilitando cambiar entre vistas. Consulta la barra de estado para ver una notificación sobre el estado actual.

## Instalación

Para instalar *ZenComPrint*:

1. Abre Visual Studio Code.
2. Navega a la vista de Extensiones haciendo clic en el icono cuadrado en la barra lateral, o presionando `Ctrl+Shift+X` (Windows/Linux) o `Cmd+Shift+X` (macOS).
3. Busca `ZenComPrint` e instálalo.

## Uso

Para alternar los comentarios y las instrucciones print:

- Presiona `Cmd+H` (macOS) o `Ctrl+H` (Windows/Linux) para alternar la visualización de comentarios y prints.

*o*

- Usa el comando `> Hide Comments & Prints` desde la paleta de comandos, accesible presionando `Cmd+Shift+P` (macOS) o `Ctrl+Shift+P` (Windows/Linux).

> [!NOTE]  
> Para ver el estado actual de los comentarios y prints, consulta la barra de estado.
